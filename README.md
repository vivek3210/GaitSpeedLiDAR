# GaitSpeedLiDAR

## A project at the [Georgia Tech Aware Home](https://awarehome.gatech.edu/).

A group based project in which a single sensor Gate Speed system was in need of being developed. 

## Hardware

-1x Adafruit ESP32 S2
-1x Garmin LiDAR L4-Lite
-1x Qwicc I2C Display
-2x Qwicc Connectors
